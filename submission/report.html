Ⅰ. 통계분석 결과 검토

jamovi로 실시한 공분산분석 결과를 생성형 AI(Claude)에 제시하고, 보고서 본문의 해석에 쓰인 통계값이 결과표와 같은지, 결과표의 값들이 서로 수학적으로 맞는지를 다시 계산하여 확인하였다(Python 3, SciPy). 검토 결과는 <표 Ⅰ-1>과 같다.

검토 결과 해석에 쓰인 모든 통계값이 결과표와 같았으며, 유의성 판단과 집단 순서도 일치하였다. 이를 바탕으로 논문에 그대로 옮길 수 있도록 다음과 같이 수정·보완하였다.

  • 분석 과정에 대한 메모(도구별 확인 사항 등)를 삭제하고, 논문 문체로 서술을 통일하였다.
  • 분석 방법 단락을 추가하여 공변량, 제곱합 유형, 사후비교 방법을 명시하였다.
  • 효과크기(부분 η²)를 추가하였다. 이 값은 표 2의 제곱합으로 계산하였다.
  • 사전 집단 차이가 있었다는 점을 해석의 제한점으로 덧붙였다.

Ⅱ. 논문 작성용 연구 결과

1. 분석 방법

세 가지 교수법(실험실습, 전통적, 멀티미디어)에 따라 학생의 과학성취에 차이가 있는지 알아보기 위하여, 교수법을 독립변수, 사후과학성취를 종속변수, 사전과학성취를 공변량으로 하는 일원 공분산분석(ANCOVA)을 실시하였다. 분석 대상은 228명(집단별 76명)이며 결측값은 없었다. 제곱합은 공변량을 먼저 투입한 Type I(순차) 방식으로 산출하였고, 교정평균 간 차이는 Scheffé 방법으로 사후비교하였다. 자료 분석에는 jamovi 2.7(R 4.5)을 사용하였으며, 결과는 Python statsmodels로 재계산하여 확인하였다. 유의수준은 .05로 설정하였다.

2. 사전 동질성 검정

교수법 집단 간 사전과학성취의 동질성을 확인하였다. Levene 검정 결과 등분산 가정이 충족되지 않아(F(2, 225) = 5.11, p = .007) Welch 검정을 적용하였다. 그 결과 사전과학성취는 집단 간 유의한 차이를 보였다(Welch's F(2, 147.65) = 3.46, p = .034). 실험실습 집단(M = 37.02, SD = 10.70)의 사전 점수가 전통적 집단(M = 40.96, SD = 11.08)과 멀티미디어 집단(M = 40.77, SD = 8.48)보다 낮았다. 따라서 집단 간 사전 차이를 통계적으로 통제하기 위하여 사전과학성취를 공변량으로 하는 공분산분석을 실시하였다.

3. 공분산분석의 가정 검토

첫째, 회귀계수의 동질성 검정에서 교수법과 사전과학성취의 상호작용이 유의하지 않아(F(2, 222) = 1.15, p = .319) 세 집단의 회귀기울기가 동일하다는 가정이 충족되었다. 둘째, 공분산분석 모형의 Levene 검정 결과 등분산 가정이 충족되었다(F(2, 225) = 0.68, p = .508). 셋째, 잔차의 Shapiro-Wilk 검정은 유의하여(W = .944, p < .001) 정규성 가정이 엄밀히 충족되지는 않았다. 그러나 집단별 표본이 76명으로 크고 집단 크기가 같으므로, 이것이 결과에 미치는 영향은 크지 않다고 판단하였다.

4. 교수법에 따른 과학성취 차이

교수법별 사전·사후 과학성취의 기술통계와 교정평균은 <표 1>과 같다. 교정 전 사후과학성취의 평균은 멀티미디어 집단(M = 43.45), 전통적 집단(M = 42.32), 실험실습 집단(M = 41.79) 순이었다.

공분산분석 결과는 <표 2>와 같다. 공변량인 사전과학성취는 사후과학성취에 유의한 영향을 미쳤다(F(1, 224) = 414.81, p < .001, 부분 η² = .649). 사전과학성취를 통제한 후에도 교수법에 따른 사후과학성취의 차이는 통계적으로 유의하였으나(F(2, 224) = 3.51, p = .032, 부분 η² = .030), 효과크기는 작은 수준이었다(Cohen, 1988). 이 모형은 사후과학성취 분산의 65.3%를 설명하였다(R² = .653).

5. 결과 해석

교정 전에는 실험실습 집단의 사후 평균이 가장 낮았으나, 사전과학성취를 통제하자 실험실습 집단의 교정평균이 가장 높게 나타났다. 이는 사전 점수가 가장 낮았던 실험실습 집단이 상대적으로 큰 성취 향상을 보였음을 의미하며, 실험실습 교수법이 과학성취 향상에 효과적일 수 있음을 시사한다. 다만 교수법의 효과크기가 작고(부분 η² = .030), 유의한 차이가 실험실습과 전통적 집단 한 쌍에서만 나타났다. 또한 수업 전 집단 간 과학성취가 동질하지 않았으므로, 결과를 일반화할 때에는 주의가 필요하다.
