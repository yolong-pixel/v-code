교수법에 따른 과학성취 차이: 공분산분석 결과

작성일 2026-11-11 · 제출본 정리 2026-11-16

1. 분석 개요

사전과학성취를 통제한 뒤에도 교수법에 따라 사후과학성취에 유의한 차이가 있었다(F(2, 224) = 3.51, p = .032). 차이는 실험실습 집단과 전통적 집단 사이에서만 나타났다.

항목내용
연구문제세 가지 교수법에 따라 학생의 과학성취에 차이가 있는가?
독립변수(요인)교수법: 실험실습, 전통적, 멀티미디어
종속변수사후과학성취
공변량사전과학성취
표본N = 228(집단별 n = 76), 결측 없음
분석 방법일원 공분산분석(ANCOVA), 제곱합 Type I(사전과학성취 먼저 투입), Scheffé 사후비교
분석 도구jamovi 2.7(R 4.5), 원자료로 Python statsmodels 재계산

2. 사전 동질성 및 가정 검토

교수법 집단 간 사전과학성취의 동질성을 확인하였다. Levene 검정 결과 등분산 가정이 충족되지 않아(F(2, 225) = 5.11, p = .007) Welch 검정을 적용하였다. 그 결과 사전과학성취는 집단 간 유의한 차이를 보였다(Welch's F(2, 147.65) = 3.46, p = .034). 실험실습 집단(M = 37.02, SD = 10.70)의 사전 점수가 전통적 집단(M = 40.96, SD = 11.08)과 멀티미디어 집단(M = 40.77, SD = 8.48)보다 낮았다. 이에 사전과학성취를 공변량으로 하는 공분산분석을 실시하였다.

공분산분석의 가정을 검토하였다. 첫째, 회귀계수의 동질성 검정에서 교수법과 사전과학성취의 상호작용이 유의하지 않아(F(2, 222) = 1.15, p = .319) 세 집단의 회귀기울기가 동일하다고 볼 수 있었다. 둘째, 공분산분석 모형의 Levene 검정 결과 등분산 가정이 충족되었다(F(2, 225) = 0.68, p = .508). 셋째, 잔차의 Shapiro-Wilk 검정은 유의하였으나(W = .944, p < .001), 집단별 표본이 76명으로 크고 균등하여 결과에 미치는 영향은 크지 않다고 판단하였다.

3. 공분산분석 결과 해석

세 가지 교수법에 따라 과학성취에 차이가 있는지 알아보기 위하여, 사전과학성취를 공변량으로 하는 일원 공분산분석을 실시하였다(표 2). 공변량인 사전과학성취는 사후과학성취에 유의한 영향을 미쳤다(F(1, 224) = 414.81, p < .001). 사전과학성취를 통제한 후에도 교수법에 따른 사후과학성취의 차이는 통계적으로 유의하였다(F(2, 224) = 3.51, p = .032). 이 모형은 사후과학성취 분산의 65.3%를 설명하였다(R² = .653).

사전과학성취를 통제한 교정평균은 실험실습 집단이 43.71(SE = 0.65)로 가장 높았다. 그다음은 멀티미디어 집단 42.56(SE = 0.64), 전통적 집단 41.29(SE = 0.64) 순이었다(표 1). Scheffé 사후비교 결과, 실험실습 집단의 교정평균은 전통적 집단보다 2.42점 유의하게 높았다(p = .032). 실험실습과 멀티미디어(p = .456), 전통적과 멀티미디어(p = .371) 간에는 유의한 차이가 없었다(표 3).

교정 전 사후과학성취의 평균은 멀티미디어(43.45), 전통적(42.32), 실험실습(41.79) 순이었다. 그러나 사전 점수가 가장 낮았던 실험실습 집단은 사전 점수를 통제하자 가장 높은 교정평균을 보였다. 이는 실험실습 교수법이 낮은 출발점에서 상대적으로 큰 성취 향상을 이끌었음을 시사한다. 다만 유의한 차이가 한 쌍에서만 나타났으므로 해석에 주의가 필요하다.

검토 결론

  • 해석 문장(분석 개요, 가정 검토, 결과 해석)에 쓰인 모든 통계값이 표 1~3의 값과 같으며, 유의성 판단(α = .05)과 집단 순서도 표와 맞는다.
  • 표 안의 값들(SS, df, MS, F, p, R², 교정평균, 신뢰구간, 사후비교)도 서로 수학적으로 맞는다. 차이는 모두 소수 둘째 자리 반올림 수준이다.
